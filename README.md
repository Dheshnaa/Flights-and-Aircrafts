## Featured Projects

### Legal Documents to Executable Prolog

A neurosymbolic AI system that converts legal terms of service into structured, executable Prolog rules.

The project combines large language models, deontic logic, and symbolic reasoning to make legal clauses easier to query and evaluate.

**Technologies:** Python, SWI-Prolog, LangChain, LangGraph, OpenAI API, RAG

**Highlights:**

- Processed more than 200 legal documents
- Extracted more than 1,000 normative clauses
- Achieved over 90% logical completeness
- Improved query execution success from approximately 70% to 95%

[View Repository](https://github.com/Dheshnaa/aiea_task_9)

### Real Estate Price Prediction

A machine learning pipeline that predicts residential property prices using historical real estate data.

The project includes data cleaning, feature engineering, categorical encoding, model tuning, and a Streamlit application for interactive predictions.

**Technologies:** Python, Pandas, scikit-learn, XGBoost, Streamlit

**Highlights:**

- Analyzed more than 100,000 real estate records
- Compared Ridge Regression, Decision Trees, and XGBoost
- Built an interactive application for property price predictions
- Achieved a test R² score of approximately 0.72 with the best model
